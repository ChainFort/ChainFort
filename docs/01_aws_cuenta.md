# Crear y organizar la cuenta AWS / Create and organize your AWS account

## 🇪🇸 Español

### Crear y organizar la cuenta AWS
- Se creó una **cuenta principal de AWS** con un correo exclusivo para la empresa.  
- Se activó **MFA (autenticación multifactor)** para proteger la cuenta root.  
- Se definió el uso de **IAM Identity Center** para la gestión de accesos y autenticación.  
- Se creó un **grupo “Administrators”** con el **Permission Set “AdministratorAccess”**.  
- Se añadió un **usuario administrador** para el uso operativo diario.  
- Se aplica el principio de **privilegios mínimos** para todos los accesos.  

---

## 🇬🇧 English

### Create and organize the AWS account
- Created a **main AWS account** with a company-exclusive email.  
- Enabled **MFA (multi-factor authentication)** for the root account.  
- Configured **IAM Identity Center** for access management and authentication.  
- Created an **“Administrators” group** with the **“AdministratorAccess” Permission Set**.  
- Added an **administrator user** for daily operational use.  
- Enforced the **least privilege principle** for all access.
