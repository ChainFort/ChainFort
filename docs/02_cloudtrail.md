# Activación de AWS CloudTrail / AWS CloudTrail Activation

## 🇪🇸 Español

### Activación de CloudTrail
- Se habilitó **AWS CloudTrail** para registrar toda la actividad en la cuenta.  
- Nombre del trail: `OrgTrail` (o `MainTrail`).  
- Se seleccionó **Apply trail to all regions** para cobertura completa.  
- Se creó un **bucket S3** exclusivo para almacenar los logs.  
- Se dejaron las configuraciones por defecto y se activó el servicio.  

**Estado:** CloudTrail activo y registrando eventos globales.

---

## 🇬🇧 English

### CloudTrail Activation
- Enabled **AWS CloudTrail** to log all account activity.  
- Trail name: `OrgTrail` (or `MainTrail`).  
- Selected **Apply trail to all regions** for full coverage.  
- Created a dedicated **S3 bucket** to store logs.  
- Left default settings and activated the service.  

**Status:** CloudTrail active and logging events globally.
