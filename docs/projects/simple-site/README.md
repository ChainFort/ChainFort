# Sitio web mínimo

Archivos incluidos:
- `index.html` — página principal.
- `styles.css` — estilos simples y responsive.
- `script.js` — comportamiento mínimo (evento de botón).
- `.gitignore` — archivos a ignorar por git.

## Cómo usar
1. Coloca todos los archivos en la misma carpeta.
2. Abre `index.html` en tu navegador (doble clic o arrastrar al navegador).
3. Para publicar en Internet: sube la carpeta a un hosting estático (GitHub Pages, Netlify, Vercel, S3 con Static Website Hosting, etc.).

## Personalizaciones rápidas
- Cambia el texto del `<h1>` en `index.html`.
- Añade imágenes en una carpeta `assets/` y referencia desde HTML/CSS.
- Para pruebas locales con recarga, puedes usar una herramienta ligera como `live-server` (opcional).
